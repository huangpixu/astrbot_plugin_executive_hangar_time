# 行政机库时间插件

用于查询行政机库时间、维护舰队编号映射，并按舰队查询 RSI 组织成员。

## 命令说明

`查命令`
- 查看全部命令和用法。
- 示例：`查命令`
- 示例：`查命令 查成员`

`行政机库时间`
- 查询接下来 10 次行政机库开启/关闭时间。

`同步行政机库时间`
- 同步行政机库起始时间。
- 示例：`同步行政机库时间`
- 示例：`同步行政机库时间 2026/01/04 17:35:08`

`添加舰队`
- 保存舰队名与 RSI 组织编号的映射到 `fleets.json`。
- 示例：`添加舰队 鹿港-GFHB`
- 示例：`添加舰队 鹿港 GFHB`

`同步舰队编号`
- 从文件重新加载舰队编号映射。

`查成员`
- 按舰队名或组织编号查询成员。
- 示例：`查成员 鹿港`
- 示例：`查成员 鹿港 2`
- 示例：`查成员 GFHB`

`查xxx成员`
- 自然语言方式查询成员。
- 示例：`查鹿港成员`

`鹿港成员`
- 兼容旧命令，等同于 `查成员 鹿港`。
